# Credit Risk Prediction Using Machine Learning

## Objective
Build a machine learning model to predict loan default risk using historical borrower and loan data.

## Dataset
Loan_default.csv (borrower demographics, loan details, default label)

## Models Used
- Logistic Regression (baseline)
- Random Forest (final model)

## Key Outputs
- Default probability
- Risk categorization
- Feature importance
- ROC curve and confusion matrix

## Tools
- Python
- Google Colab
- Scikit-learn
